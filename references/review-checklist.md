# Review Checklist

## 字幕

- 是否逐字忠于用户稿件或真实转写；
- 专有名词、数字、产品名是否正确；
- 是否出现超前/滞后；
- 单屏字数和停留时间是否可读；
- 强调词是否与语义重音一致；
- 是否越过安全区或遮挡面部。

## 开场与内容

- 前 3 秒是否立即给出问题、结果或冲突；
- 是否存在无信息价值的片头；
- 画面是否帮助理解口播；
- 是否每句话都乱切场；
- CTA 是否单一明确。

## 人物与图层

- 人物是否在转场中连续存在；
- 是否有黑场、闪帧、明暗突变；
- 蒙层是否误盖人物；
- 人脸是否被字幕、卡片或裁剪遮挡；
- 全屏→卡片→全屏是否位置、比例连续；
- `zIndex` 和 DOM 顺序是否符合设计。

## 动画

- 是否由帧驱动；
- 动画开始和结束是否踩中语义；
- 是否过度弹跳、过快或拖沓；
- 数字增长是否有足够结束停留；
- 转场是否造成内容阅读中断；
- 是否无意义堆叠特效。

## 布局

- 字号是否适合手机；
- 卡片内边距、对齐和行高是否一致；
- 重要信息层级是否明确；
- 画面是否过空或过满；
- 边缘元素是否处于平台安全区内。

## 音频和媒体

- 音画是否同步；
- 代理与原片时长是否一致；
- 是否有爆音、突然静音或重复音轨；
- 视频裁剪和旋转是否正确；
- 外部素材是否加载稳定。

## 渲染前

- 用户是否明确授权最终导出；
- Composition ID 是否正确；
- `mediaMode` 是否已切回 source；
- 分辨率、FPS、总帧数是否符合目标；
- 字体和媒体是否可离线访问；
- 输出路径是否不会覆盖原始素材；
- 是否完成代表性帧检查；
- 是否记录 Git/文件状态以便回退。

## 渲染后

- 文件存在且不是 0 字节；
- 编码、宽高、FPS、时长正确；
- 音轨存在；
- 开头、中段、结尾抽查无黑帧；
- 最终报告包含路径和验证结果。

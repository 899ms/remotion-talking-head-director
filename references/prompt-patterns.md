# Prompt Patterns

以下模板供 Codex 在需要向用户展示“下一步可复制指令”时使用。Skill 本身应直接执行能够安全执行的工作，不要把所有步骤都推回给用户。

## 1. 首次启动

```text
使用 remotion-talking-head-director 处理当前项目中的口播素材。
先执行 P0-P2：检查素材、转写并生成时间码、建立720p代理和素材清单。
不要设计完整视频，不要渲染最终MP4。完成后给出文件位置和阻塞问题。
```

## 2. 风格阶段

```text
继续执行 P3。分析我提供的参考截图，先建立视觉规范，并制作开场、中段数据展示、结尾CTA三个关键帧。
不要制作完整时间轴，不要最终渲染。等待我确认视觉方向。
```

## 3. 确认后开发

```text
风格确认，继续执行 P4-P5。根据真实逐字稿制作语义分镜并实现 Remotion 时间轴。
使用代理素材，启动 Studio，提供 Composition ID 和预览入口。不要导出最终视频。
```

## 4. 精确修改

```text
目标区间：第118帧到第138帧。
目标元素：人物视频。
修改：从全屏缩小为宽360px的卡片，并移动到右下角。
图层：人物高于背景和蒙层，文字不得遮挡面部。
限制：不得修改其他场景，只更新 Studio 预览，不要渲染。
```

## 5. 数字动效

```text
在口播提到“10万人观看”对应的时间段，把数字做成从0增长到100,000+。
动画必须在关键词说完前完成，结束后至少保留可读时间；不能遮挡人物和字幕。
```

## 6. 图层故障

```text
人物缩小时出现黑场并在开头变暗。请只读检查 zIndex、AbsoluteFill顺序、蒙层、opacity、Sequence重叠、overflow和人物组件挂载状态。
先输出根因和影响帧，不要立即用硬切掩盖问题。确认根因后再修复并只更新Studio预览。
```

## 7. 只读评审

```text
执行 P7，只读评审当前预览，不要修改代码。
分别检查字幕同步、视觉层级、动画转场、人物黑场/遮挡、前3秒留存，并按时间码和帧数输出问题清单。
```

## 8. 最终导出

```text
确认，可以导出。执行 P8：保存确认版本，切回原始高分辨率素材，完成抽帧验证后渲染最终视频。
输出到 out/final-4k.mp4，不得覆盖源视频。渲染后验证编码、分辨率、帧率、时长、音轨和文件大小。
```
